# Админ-панель Royal Select — как подключить

Админ-панель открывается по адресу `ваш-сайт/admin.html`.
В ней можно с телефона добавлять, менять и удалять ароматы и отзывы,
ставить «Хит продаж» и «Нет в наличии». Изменения сразу видны на сайте.

Данные и вход хранятся в **Firebase** (сервис Google). Для небольшого магазина он бесплатный.
Настроить нужно один раз, это займёт около 15 минут.

---

## Шаг 1. Создайте проект

1. Откройте <https://console.firebase.google.com> и войдите через Google-аккаунт.
2. Нажмите **«Создать проект»** (Create a project), название — `royal-select`.
3. Google Analytics можно отключить. Нажмите **«Создать»**.

## Шаг 2. Получите настройки для сайта

1. На главной странице проекта нажмите значок **`</>`** (Web).
2. Название приложения — `royal-select-site`. Firebase Hosting **не** отмечайте. Нажмите **«Зарегистрировать»**.
3. Появится блок кода с `const firebaseConfig = { apiKey: ..., ... }`.
   **Скопируйте его и пришлите разработчику** (или вставьте в файл `firebase-config.js`).
   Это не секретные данные: их можно показывать, доступ защищают правила из шага 5.

## Шаг 3. Включите вход по логину и паролю

1. Слева: **Build → Authentication → «Начать»** (Get started).
2. Вкладка **Sign-in method** → **Email/Password** → включите первый переключатель → **Сохранить**.
3. Вкладка **Users** → **Add user**: впишите ваш e-mail (это логин) и придумайте пароль.
   Пароль — не короче 8 символов, не такой, как у почты.
4. Вкладка **Settings → User actions**: **снимите** галочку «Enable create (sign-up)»,
   чтобы посторонние не могли регистрироваться.
5. Там же **Settings → Authorized domains**: добавьте домен сайта
   (например, `ваш-логин.github.io` или `royalselect.kz`).

## Шаг 4. Создайте базу данных

1. Слева: **Build → Firestore Database → «Создать базу данных»**.
2. Расположение — **eur3 (Europe)** или ближайшее. Режим — **Production**.

## Шаг 5. Защитите базу

1. В Firestore откройте вкладку **Rules** (Правила).
2. Удалите всё, что там написано, и вставьте содержимое файла `firestore.rules`.
3. Замените `admin@example.com` на e-mail из шага 3. **Опубликуйте** (Publish).

Теперь читать ароматы может любой посетитель, а менять — только вы.

## Шаг 6. Первый вход

1. Откройте `ваш-сайт/admin.html`, войдите с e-mail и паролем из шага 3.
2. Нажмите **«Загрузить начальные данные»** — в базу попадут ароматы, которые сейчас на сайте.
3. Дальше редактируйте как удобно.

---

## Если что-то не работает

| Сообщение | Что делать |
|---|---|
| «Админ-панель ещё не подключена» | Не заполнен `firebase-config.js` (шаг 2) |
| «Неверный логин или пароль» | Проверьте пользователя в Authentication → Users |
| «Нет прав на изменение» | E-mail в правилах (шаг 5) не совпадает с вашим логином |
| Вход не открывается на сайте | Домен сайта не добавлен в Authorized domains (шаг 3.5) |

Забыли пароль — в Authentication → Users нажмите ⋮ рядом с пользователем → **Reset password**.
